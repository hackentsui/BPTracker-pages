# BPTracker Support

This repository hosts the basic support page for the BPTracker app.

## About BPTracker

BPTracker is a simple blood pressure tracking app designed to help users record and review their blood pressure readings for personal reference.

## Features

* Record systolic and diastolic blood pressure
* Record pulse rate
* Add notes for each reading
* View recent records
* Review saved blood pressure data
* Designed for personal health tracking reference

## Support

If you need help with the BPTracker app, please open an issue in this repository.

To request support:

1. Go to the Issues tab
2. Create a new issue
3. Describe your question or problem clearly

Please do not include personal health information or sensitive personal data when opening a public GitHub issue.

We will review support requests submitted through GitHub Issues.

## Privacy Policy

BPTracker is designed for personal use and does not require users to publish personal information on this support page.

The app may store blood pressure records, pulse readings, notes, and related health tracking information locally on the user’s device.

BPTracker does not sell user data.

BPTracker does not use personal data for advertising.

BPTracker does not require users to create a public profile.

Any health tracking information entered into the app is intended for the user’s own reference only.

Users are responsible for managing and protecting the data stored on their own device.

This app is not a medical device and does not provide medical diagnosis, treatment, or professional medical advice. Users should consult a qualified healthcare professional for medical concerns.

## Data Deletion

If the app stores data locally on the user’s device, users may delete their records within the app where supported, or remove the app from their device to delete locally stored app data.
